# Widget Documentation Index

This folder contains one Markdown document per widget type.

## Folder Contract

- Location: `src/HornetStudio/docs/widgets/`
- One file per widget type
- File name matches the persisted widget `Type` value
- Example lookup: `src/HornetStudio/docs/widgets/<Type>.md`
- Detailed help file lookup: `src/HornetStudio/docs/widgets/help/<Type>.help.md`

## Available Widget Docs

- `ApplicationExplorer.md`
- `Button.md`
- `CameraControl.md`
- `ChartControl.md`
- `CircleDisplay.md`
- `DialogWidget.md`
- `Item.md`
- `WidgetList.md`
- `LogControl.md`
- `PythonClient.md`
- `Signal.md`
- `TableControl.md`
- `Functions.md`

This naming scheme is intended to make later in-app document lookup straightforward.

For property-level and function-level help, see `src/HornetStudio/docs/widgets/help/index.md`.
