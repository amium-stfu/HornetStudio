Signal

Compact value widget for displaying and editing a single target value.

- Shows live values from a connected target
- Uses a shared live-value scheduler for attached UDL steady-state updates
- Supports formats, units, and value input with automatic write-property routing
- Can optionally enable central history recording for charts
- Keeps the body editable when the displayed value is empty
- Works well for status values and direct property access

Best for:
Single signals that should stay easy to read and edit.
