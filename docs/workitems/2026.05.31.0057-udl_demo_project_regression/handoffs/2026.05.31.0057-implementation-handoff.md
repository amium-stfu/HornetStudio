## Goal
Restore the `samples/HornetStudioDemo` project after the UDL client architecture migration. The demo must load cleanly, start the file-backed UDL demo client from `Clients/Udl/udl1.yaml`, and expose the expected runtime/status data without relying on stale widget-local UDL configuration.

## Scope
Included:
- Diagnose why the demo project currently does not run after the UDL client migration.
- Validate and repair `samples/HornetStudioDemo/Folders/main/Folder.yaml` if stale UDL demo fields were left behind during migration.
- Validate `samples/HornetStudioDemo/Folders/main/Clients/Udl/udl1.yaml`.
- Verify that the folder load path reads `Clients/Udl/*.yaml` and calls UDL runtime synchronization.
- Verify that `AutoConnect=true` and `DemoEnabled=true` create/start the expected runtime.
- Verify that the attached demo module `m001` is available through the intended runtime/status/attached item paths.
- Add or adjust focused tests if the regression can be covered cheaply.

Explicitly not included:
- Redesigning the UDL browser layout.
- Adding a separate UDL view/status widget.
- Broad refactoring of the UDL runtime architecture.
- Changing the chosen file layout `Clients/Udl/<client-id>.yaml`.
- Release/versioning work.
